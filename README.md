# AI Video Master

A responsive AI video tool directory built with plain HTML and CSS. It includes compact themed icons and direct links that open in a new tab. No package installation or build step is required.

Open `index.html` in a browser to run it locally.

## GitHub Pages

1. Push this project to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose your branch and the repository root (`/`).
4. Save to publish the site.

## Auto-commit and push on save

The workspace recommends the **Run On Save** extension. When it is installed and enabled, saving a changed existing file runs `git add .`, commits staged changes as `Auto update` when there are any, and pushes `main` to `origin`. The workspace pins the command shell to Windows `cmd.exe` so the `&&` sequence behaves consistently.

This stages and commits all repository changes, not only the saved file. Review changes and ensure no secrets or unwanted files are present before saving: saved changes are pushed to the remote automatically. GitHub Pages publishes after its deployment workflow completes, so updates are not guaranteed to appear instantly. The extension only triggers for existing files; creating a file or using Save As does not trigger its command.
