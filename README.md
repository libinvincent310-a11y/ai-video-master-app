# AI Video Master

A responsive AI video tool directory built with plain HTML and CSS. It includes compact themed icons, direct links that open in a new tab, and a free-access disclaimer. No package installation or build step is required.

Open `index.html` in a browser to run it locally.

## GitHub Pages

1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose your branch and the repository root (`/`).
4. Save to publish the site.
